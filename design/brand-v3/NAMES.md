# Tuner v3: name shortlist

The owner said the name is open: "tuner does seem like an engineering software though but it is clean". This is the shortlist, with the checks he asked for. The app is personal and not sold, so "clash" here means *confusion with a known brand or app*, not legal clearance. **Nothing below is trademark-cleared.**

## How the checks were done (and their limits)

- **Clash:** web searches for each name against streaming, IPTV, sports and movie apps, App Store and Google Play listings that the search engine surfaces, and well-known brands. I did not query the stores directly, so "no hit" means "nothing turned up in search", not "free". Re-check in the App Store and Play Store before committing.
- **Read from across a room / say it:** judged on rendered wordmarks (`directions.png`, the TV mocks) at 1080p plus how the word sounds: syllables, hard consonants, mishearing risk.
- **One-word wordmark:** does the name make a good outlined logotype alone: letter count, letter shapes, a natural T/A/S to build a mark on.
- Naming principles used (from streaming-naming write-ups): keep it short because it must fit under an icon; do not box the app into one genre; evocative names need more help to land than descriptive ones, which does not matter for a personal app; check store and brand conflicts early ([VentureBeat](https://venturebeat.com/business/shouldnt-entertainment-brand-names-be-entertaining), [Prophet](https://prophet.com/?p=8623), [Webflow naming guide](https://www.webflow.com/blog/how-to-come-up-with-a-brand-name)). Peacock is cited as the model of a distinctive, fun-to-say name.

## Which direction uses which name

| Direction | Name | Why that name |
|---|---|---|
| 1 Slate (cinema / title card) | **SLATE** | the clapperboard is the mark |
| 2 Tipoff (live sports) | **TIPOFF** | the italic T and wedge are the mark |
| 3 Airtime (colour as light) | **airtime** | the A-shaped play button is the mark |
| 4 Test card (broadcast heritage) | **TUNER** | the name stays; the bars make "engineering" into the joke |

## My ranking if the name were picked alone

1. **TIPOFF** for the NBA-first reality; 2. **SLATE** if movies and shows should lead; 3. **TUNER** if a safe, clean, already-owned word is enough; 4. **airtime**. The four avoids are a real conflict, not a taste call.

## Still to do before any name sticks

- Say it out loud next to "Grizzlies", "League Pass" and the other app names in the launcher row.
- Check a short domain and handle if there is ever a reason to publish.
